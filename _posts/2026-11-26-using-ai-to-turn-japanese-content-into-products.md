11 月马上就要结束了，我计划已久的产品开发工作终于步入正轨，或者说，我终于找到了做产品的「気持ち」。

切换工作节奏对我来说并不容易，这是个人特质决定的，对此我坦然接受。除此之外，我还要兼顾内容、产品和营销，切换工作范畴就像切换线程上下文一样，需要消耗一些精力。

自从开启内容创业以来，我一直在用程序员时代养成的「工程师思维」来管理商业流程，其中「用技术打造极致的运营效率」便是经营理念之一。

## 开发 CMS，高效管理数据

为了更高效地管理内容，从创业一开始，我就手写代码开发了一套内容管理系统。这套系统经过一轮又一轮的迭代，逐渐演化成了一个「内容工厂」，源源不断地为社媒账号输送内容。

去年用上 Claude Code 之后，功能迭代进一步加速。只要哪里用得不太顺手，我就随手 Vibe Coding 一下。经过不断优化，现在用起来特别顺畅。这个系统除了生产内容，还能制作 PDF 电子书。

这些功能之所以能快速上线，很大程度上得益于数据的结构化存储。其中，有一部分数据还孵化出了下面这个产品。

## 开发 iPad App，快速录制语法讲解视频

为了快速制作语法讲解短视频，我还开发了一个 iPad App。利用系统自带的录屏功能和 Pencil 的标注功能，一边操作 App，一边讲解知识，再加上 AI 的辅助，几分钟就能制作一条视频。当然了，这个工作流也经历了很多次探索和改进，不是一蹴而就的。

这个 App 让我实现了内容自由，即使每天更新一条，库存也足以支撑到明年下半年。

AI 大幅提升了我的工作效率，让我从枯燥乏味的工作中解放出来，从而拥有了更多时间去读书、思考、陪伴孩子——这可能就是科技之于我的意义。

## 接下来，把内容做成产品

接下来，我想进一步利用好 AI，将过去三年积累下来的「内容」一步步转化成有科技感的「产品」，走好商业闭环的最后一步。

### 一、制作付费视频课程

「视频课程」是实现内容变现的有效手段，但是市面上的课程同质化现象严重，缺乏新意，所以我想做点不一样的。

首先，抛弃传统的幻灯片，改用写代码的方式制作课件，利用 Vibe Coding 将静态文本转化成交互性极强的 App；然后，打开屏幕录制，一边操作一边讲解；最后，交给 AI 粗剪，调整长宽比，优化声音，生成字幕。

这种方式不但能满足课程录制的需求，做好的课件还可以快速转为线上产品，Web 和 App 都可以。

### 二、开发在线学习平台

课程制作简单，但是交付困难。一方面，依托平台分发，限制条件太多，交付也局限于单一渠道；另一方面，如果付费订阅 SaaS，费用高不说，效果还不一定好。真不如自己开发一套，既能满足个性化需求，也不用受制于外部系统。

如果放在两年前做这件事，那一定是不明智的。但在 AI 时代，开发个课程系统还不是分分钟的事。

所以，开发在线学习平台的时机已经成熟了。把录制好的课程发布到上面，就能不依附于平台，独立交付课程。另外，微信服务号也要利用好，向「马同学图解数学」学习。

### 三、开发学习类 App

这类产品的核心价值是通过技术手段提高语言学习效率。除了阅读相关书籍，我还可以从小朋友的英语课程中汲取灵感。

目前有两个产品正在开发中：「五十音 App」和「语法大全 App」。功能上很难做出亮点，只能在交互上发力了。具体可见[《日语内容如何变现：为什么先做五十音和 JLPT 语法 App》]({% post_url 2026-11-17-thoughts-on-products %})、[《先做五十音 App：把开发、推广和变现走一遍》]({% post_url 2026-11-19-build-the-kana-app-first %})。

开发这类产品是我一直以来的夙愿。当初做 Android 开发时，我就构想过很多种语言学习产品，可惜执行力有限，至今没有上线过一款产品。

这一次，先不管有没有人会用，启动起来再说。

### 四、开发学习类 Web 小游戏

Web 小游戏和 App 的产品思路一脉相承，都是为了提高语言学习效率，只不过表现形式不一样。

小游戏的发布更加简单，直接用 GitHub Pages 就可以，关键是想法。

### 五、制作电子书

目前我已经积累了两套语法教程，可以直接生成 PDF。另外，CMS 中存储的 JLPT 语法条目，也支持一键生成 PDF。

也就是说，只要内容准备好了，生成 PDF 就是水到渠成的事。

- 写一套日语入门教程
