---
title: 我用 Codex 重构工作流，发现效率不是问题
---

自从用 Codex + GitHub 重构工作流，我的效率像开了挂：现在一天的产出，抵得上以前一周。

我每天站着办公，右手边的显示器上排着十几个亮着蓝点的 Codex 对话窗口，像一支训练有素的队伍，各自领了任务，埋头干活。写代码、剪视频、写文稿、处理 GitHub issues，样样拿得出手。

我是一人公司的老板，大部分时间只有自己，但有了这群 AI 员工，倒也不觉得孤独。

为了这套工作流，我卸载了飞书，删掉了 Obsidian，把内容、产品和项目全部搬到 GitHub，再用 Codex 把整个商业流程串起来。

再也不用关心这个工具多逆天，那个软件多牛逼，世界一下子安静了。

近期成果也算丰硕：同时运营四个社交平台，保持日更，省出来的时间，正好拿来专心做产品、攒内容。

看着脑子里的想法一个个变成现实，我本该得意。可当我关掉视频号，打开 B 站，看看年轻人都在玩什么，才发现自己做的内容，确实有点老套了。
